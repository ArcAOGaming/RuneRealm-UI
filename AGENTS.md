# Rune Realm — agent rules

The rules for this repository live in [CLAUDE.md](CLAUDE.md), which is the
single source of truth for every agent and every human working here. Read it
first, then [HANDOFF.md](HANDOFF.md), which is the map of the codebase.

This file exists so tools that look for `AGENTS.md` find the rules. It is
deliberately a pointer and not a copy: two lists of rules become two different
lists of rules within a month.
